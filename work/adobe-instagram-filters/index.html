Overview

One set, one theme, five apps.

For Swinburne’s Orientation Week event and Adobe’s partnership seminars, I designed interchangeable Instagram filters using Meta’s Spark AR. Each filter draws on UI and creative elements from specific Adobe Creative Suite applications, creating a cohesive theme across the set.
